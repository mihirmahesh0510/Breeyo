<objective>
Build three feature clusters for the consultation screen: (1) voice-to-text transcription with record-then-transcribe pattern and medical term formatting, (2) file attachment workflow with camera/gallery/file picker, S3 upload, and 10MB limits, (3) medical history timeline with bottom sheet, preventive care card, weight trend chart, and PDF document generation (4 templates). This plan runs parallel to Plans 04 and 05.

Purpose: Voice-to-text is the speed multiplier for busy vets. File attachments capture lab/imaging results. Medical history gives clinical context during consultation. PDFs are critical outputs (vaccination certificates for compliance, prescription pads for owners).

Output: Voice transcription, file upload, history timeline, preventive care tracking, and 4 PDF document types.
</objective>

    `prescription-pad.ts` (D-47):
    - `buildPrescriptionPadHtml(clinic, consultation, prescriptions)`: Use exact pattern from RESEARCH.md Pattern 4 (lines 492-554). Traditional Rx pad format: clinic header, patient info, Rx symbol, numbered medications with owner-friendly instructions, route, dispensed/prescribed. Vet signature line at bottom.

    `vaccination-certificate.ts` (D-41):
    - `buildVaccinationCertificateHtml(clinic, certificateData)`: Formal certificate format. Clinic header, pet details (name, species, breed, age, weight, microchip if available), owner details, vaccine name, batch/lot number, manufacturer, expiry date, date administered, next due date. Vet name + license. "This is to certify that the above animal has been vaccinated against [vaccine]." Suitable for rabies compliance.

    **2. Create `useGeneratePdf.ts`**:
    - `generatePdf(html: string, filename: string)`:
      1. Call `Print.printToFileAsync({ html })` to generate PDF
      2. Move from cache to meaningful filename: `FileSystem.moveAsync({ from: uri, to: cacheDir + filename + '.pdf' })`
      3. Open native share sheet: `Sharing.shareAsync(pdfUri, { mimeType: 'application/pdf', dialogTitle: 'Share ' + filename, UTI: 'com.adobe.pdf' })`
    - `generateOwnerSummary(consultationId)`: Load consultation data, call buildOwnerSummaryHtml, generatePdf
    - `generateClinicalRecord(consultationId)`: Load full consultation, call buildClinicalRecordHtml, generatePdf
    - `generatePrescriptionPad(consultationId)`: Load consultation + prescriptions, call buildPrescriptionPadHtml, generatePdf
    - `generateVaccinationCertificate(petId, vaccinationId)`: Load certificate data from API, call buildVaccinationCertificateHtml, generatePdf
    - Export: `{ generateOwnerSummary, generateClinicalRecord, generatePrescriptionPad, generateVaccinationCertificate, isGenerating }`
