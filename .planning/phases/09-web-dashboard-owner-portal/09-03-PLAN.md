<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser inventory UI → inventory web APIs | Untrusted browser edits can mutate live stock and batch state |
| Export endpoints → downloadable files | Export actions can leak inventory data if scope or format is too broad |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-07 | Tampering | Inventory stock-change endpoints | mitigate | Route risky browser adjustments through explicit reason-bearing endpoints plus `RiskyStockChangeDialog`, never through hidden inline writes |
| T-09-08 | Information Disclosure | Inventory analytics exports | mitigate | Scope exports to the authenticated clinic inventory dataset only and expose exports from the inventory module, not a global report surface |
| T-09-09 | Elevation of Privilege | Browser scanning boundary | mitigate | Reject browser barcode-capture flows in API/UI and direct scanning to mobile-only flows per D-37 |
</threat_model>
