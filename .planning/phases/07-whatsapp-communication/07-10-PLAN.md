<objective>
Build the WhatsApp booking conversation (WHA-03): slot generation from the clinic's working hours, the booking state machine with auto-confirmation, first-come-first-served slot arbitration by database unique constraint, staff-only move and cancel, and the inbound handler that plugs into the router built in 07-09.

Together these give the convenience of a booking bot without pretending a calendar exists — an honest stopgap, with `supersededByAppointmentId` already in place so Phase 8 can adopt these records.

Output: slot service, transition guard, booking service, booking repository, the inbound handler, two unit suites, and the booking and booking-concurrency integration suites.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| owner inbound payload → booking state transition | Owner-controlled ids drive state changes |
