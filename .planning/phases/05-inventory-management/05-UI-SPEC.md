# Phase 5 -- UI Design Contract

> Visual and interaction contract for Inventory Management. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> This phase brings barcode scanning, batch/lot/expiry management, FIFO dispensing, par-level alerts, stock-taking, want-lists, and offline scanning to Breeyo. All tokens, base components, and interaction patterns from 02-UI-SPEC.md are inherited and NOT re-declared here. Phase 3 patterns (live search, timeline, optional photo) and Phase 4 patterns (accordion, floating bar) are reused where applicable. This document specifies what Phase 5 adds or refines for inventory screens.

## Spacing Scale

Inherited from Phase 2 UI-SPEC (8px base unit). No modifications.

| Token | Value | Phase 5 Usage |
|-------|-------|---------------|
| `spacing.xs` | 4px | Icon-to-label gap in inventory cards, badge internal padding, stock level indicator padding |
| `spacing.sm` | 8px | Category filter chip spacing, batch list row internal spacing, stock movement timeline icon gap |
| `spacing.md` | 16px | Inventory card internal padding, form field gaps in stock receipt form, bottom sheet content padding, scan result card padding |
| `spacing.lg` | 24px | Section gaps within item profile tabs, gap between summary header and item list, Attention card internal section padding |
| `spacing.xl` | 32px | Screen-level horizontal margins, gap between summary cards row and list area |
| `spacing.2xl` | 40px | Vertical gap above scanner action area |
| `spacing.3xl` | 48px | Bottom padding above tab bar safe zone |

Exceptions:
- **Touch targets**: 44x44pt minimum enforced on all inventory cards, filter chips, sort selector, scanner quick-action buttons, barcode manual entry button, torch toggle (Phase 2 standard).
- **Summary header card height**: 64px per summary card (Total Items, Low Stock, Expiring Soon, Total Value).
- **Inventory list card height**: 72px per card (name + category icon + stock level + selling price + expiry badge -- balanced density per Phase 2 D-32).
- **Scanner overlay controls**: Torch toggle and manual entry button positioned 16px from screen edges with 48px tap target (minimum 44pt + 4px visual breathing).
- **Bottom sheet scan result snap points**: 30% (single item peek) and 60% (expanded list for continuous scanning).
- **Dispense form quantity stepper**: 48px height per stepper button (large touch target for one-handed operation while holding animal/product).

### Stock Level Color Map (Claude's Discretion)

| Stock Status | Condition | Text Color | Icon | Background |
|-------------|-----------|-----------|------|------------|
| Healthy | `currentStock >= parLevel * 0.75` | `primary` (#2E7D32) | `check-circle` | none |
| Warning | `currentStock >= parLevel * 0.25` AND `< parLevel * 0.75` | `tertiary` (#E65100) | `alert-circle-outline` | none |
| Critical | `currentStock < parLevel * 0.25` OR `currentStock === 0` | `error` (#BA1A1A) | `alert-circle` | none |
| No par level | `parLevel === null` | `onSurfaceVariant` (#49454F) | none | none |

### Expiry Status Color Map

| Status | Condition | Badge Background | Badge Text |
|--------|-----------|-----------------|-----------|
| Expired | `expiryDate <= today` | `errorContainer` (#FFDAD6) | `onErrorContainer` (#410002) |
| Expiring soon | `expiryDate <= today + leadDays` AND `> today` | `tertiaryContainer` (#FFE0B2) | `onTertiaryContainer` (#BF360C) |
| OK | `expiryDate > today + leadDays` | none (no badge) | -- |
| No expiry | `expiryDate === null` (non-medicine category) | none (no badge) | -- |

```
  |     -> ScanResultBottomSheet snaps to 30% (peek)

```

```
  |
  v
```

```
  -> Stop on first failure, retry later
  -> Banner dismisses
  -> React Query cache invalidated (fresh data from server)
```
