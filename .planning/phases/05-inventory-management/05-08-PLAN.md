<objective>
Add HSN/SAC code and GST rate fields to inventory items for GST-compliant invoicing (INV-09). This plan extends the InventoryItem model with two optional fields -- hsnSacCode (String, max 8 chars) and gstRate (Decimal(5,2), nullable) -- across the full stack: Prisma schema, shared types, zod validators, API service/repository, and mobile UI (item form and item profile).

Purpose: Phase 6 plan 06-04 (BIL-07 GST compliance) assumes InventoryItem carries hsnSacCode and gstRate so the GstService can look up per-line-item HSN/SAC codes and GST rates when building invoices. Without these fields on the inventory item, invoice line items cannot carry product-specific GST information, and the clinic would need to manually enter HSN codes on every invoice -- defeating the purpose of a streamlined billing flow for solo vets.

Output: Prisma migration adding two columns (additive, no data loss), updated shared types and validators, updated item CRUD API, common veterinary HSN code reference constants, updated mobile item form with HSN/SAC input and GST rate picker, and updated item profile Details tab showing these fields.
</objective>
