    - `createVaccination(clinicId, petId, consultationId, data)`: Create VaccinationRecord. data includes { vaccineName, batchNumber, manufacturer, expiryDate, administeredBy, nextDueDate }.

    - `createDeworming(clinicId, petId, consultationId, data)`: Create DewormingRecord. data includes { drugName, administeredBy, nextDueDate }.

    **2. Create `apps/api/src/modules/vaccination/vaccination.service.ts`:**

    Class `VaccinationService` with constructor accepting VaccinationRepository:

    - `createVaccination(clinicId, petId, consultationId, petSpecies, petAgeDays, data)`:
      1. If data.nextDueDate not provided, auto-calculate using `calculateNextDueDate(data.vaccineName, petSpecies, petAgeDays, data.administeredAt || new Date())`
      2. Call repository.createVaccination(...)

    - `createDeworming(clinicId, petId, consultationId, petSpecies, petAgeDays, data)`:
      1. Calculate next due date from DEWORMING_INTERVALS based on pet age bracket:
         - age < 90 days: 14-day interval (puppy/kitten)
         - age 90-180 days: 30-day interval (young)
         - age >= 180 days: 90-day interval (adult)
      2. Allow manual override if data.nextDueDate provided
      3. Call repository.createDeworming(...)

    - `getPreventiveCareStatus(clinicId, petId): Promise<PreventiveCareStatus>`:
      1. Get overdue vaccinations: repository.getOverdueVaccinations()
      2. Get due-soon vaccinations: repository.getDueSoonVaccinations()
      3. Get latest deworming: repository.getLatestDeworming()
      4. Determine vaccination status:
         - If any overdue: 'overdue', collect vaccine names
         - If any due within 7 days: 'dueSoon'
         - Otherwise: 'upToDate'
      5. Determine deworming status:
         - If latest deworming nextDueDate < now: 'overdue'
         - If latest deworming nextDueDate within 7 days: 'dueSoon'
         - If no deworming records: 'overdue' (never dewormed = overdue)
         - Otherwise: 'upToDate'
      6. Return PreventiveCareStatus with both statuses and next due dates

    - `getVaccinationHistory(clinicId, petId)`: repository.getVaccinationRecords()

    - `getDewormingHistory(clinicId, petId)`: repository.getDewormingRecords()

    - `getCertificateData(clinicId, petId, vaccinationId)`:
      1. Load vaccination record
      2. Load pet with owner
      3. Load clinic details (name, address, phone, logo)
      4. Load vet details (name, license number)
      5. Return structured object: { clinic: { name, address, phone, logoBase64 }, pet: { name, species, breed, age, weight, owner: { name, phone } }, vaccine: { name, batchNumber, manufacturer, expiryDate, administeredAt, nextDueDate }, vet: { name, licenseNumber } }
