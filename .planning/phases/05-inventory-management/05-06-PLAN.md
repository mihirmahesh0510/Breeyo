<objective>
Build the mobile stock receipt screen, dispense screen with FIFO batch display, and stock adjustment bottom sheet. These screens handle the core stock movement operations: receiving new stock, dispensing with FIFO enforcement, and manual adjustments.

Purpose: These screens complete the stock operation UI. They are launched from the item profile action buttons (Plan 04) and scanner quick actions (Plan 05). The dispense screen is the most critical -- it must correctly show FIFO batch selection and handle the expired batch blocking UX, and (per plan-review decision D-60) let counter sales optionally attach a pet owner so Phase 6 can later turn un-invoiced dispense records into real invoices.

Output: Three complete stock operation screens/sheets with all supporting components and API integration.
</objective>
