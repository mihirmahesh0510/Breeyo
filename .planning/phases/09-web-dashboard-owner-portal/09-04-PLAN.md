<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser queue/billing UI → queue and billing APIs | Untrusted browser actions can change queue status or billing state |
| Realtime event stream → browser stale-state UI | Bad event metadata can hide conflicts or misrepresent who changed what |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-10 | Tampering | Queue and billing mutations | mitigate | Keep all browser actions behind authenticated queue/billing routes with server-side role checks and no client-trusted permission flags |
| T-09-11 | Repudiation | Risky billing actions | mitigate | Return actor and timestamp metadata for refund/void history and render them beside high-risk UI actions |
| T-09-12 | Information Disclosure | Realtime stale-state payloads | mitigate | Emit only clinic-scoped change metadata (`staleVersion`, actor, changed time, review path) and never cross-clinic record contents |
</threat_model>
