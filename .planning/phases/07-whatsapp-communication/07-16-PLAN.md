## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Admin config screen → provider selection | A configuration change can decide whether real owners are messaged |
| staff number correction → outbound destination | An edited phone number changes who receives a message |
| owner preference toggle → compliance state | Opt-out state is a DPDP-relevant record |
| launcher props → send payload | Any surface can construct a send request |
