    **1. Create `apps/api/src/modules/inventory/middleware/inventory-permissions.middleware.ts`:**

    ```typescript
    const INVENTORY_PERMISSIONS = {
      viewInventory: ['admin', 'clinician', 'inventory_manager', 'front_desk'],
      manageStock: ['admin', 'inventory_manager', 'front_desk'],
      dispense: ['admin', 'clinician', 'inventory_manager'],
      setPricesAndParLevels: ['admin', 'inventory_manager'],
      exportData: ['admin', 'inventory_manager'],
    } as const;

    export function requireInventoryPermission(action: keyof typeof INVENTORY_PERMISSIONS) {
      return async (request: FastifyRequest, reply: FastifyReply) => {
        const userRole = request.user.role;
        const customPerms = request.user.customPermissions;
        if (!INVENTORY_PERMISSIONS[action].includes(userRole) && !customPerms?.[action]) {
          return reply.status(403).send({ error: { code: 'FORBIDDEN', message: `Permission denied: ${action}` } });
        }
      };
    }
    ```

    **2. Create `apps/api/src/modules/inventory/inventory-item.repository.ts`:**

    Class `InventoryItemRepository` with PrismaClient:

    - `create(clinicId, input: CreateItemInput)`: In transaction: create InventoryItem, then createMany InventoryBarcode entries for each barcode in input.barcodes. Set currentStock=0, isActive=true. Return item with barcodes.

    - `update(clinicId, itemId, input: UpdateItemInput)`: Update InventoryItem fields. Return updated item.

    - `findById(clinicId, itemId)`: Find InventoryItem with include { barcodes: true, batches: { where: { currentQty: { gt: 0 }, isExpired: false }, orderBy: { receivedAt: 'asc' } } }. Return item or null.

    - `list(clinicId, { search?, category?, sort?, page?, limit? })`: Build query with:
      - If search (length >= 2): Use raw SQL with `similarity(name, $search) > 0.15 OR name ILIKE '%' || $search || '%' OR EXISTS (SELECT 1 FROM inventory_barcodes WHERE item_id = inventory_items.id AND code LIKE '%' || $search || '%')`. Order by similarity score when searching.
      - If category: WHERE category = $category
      - Sort mapping: 'name_asc' -> { name: 'asc' }, 'stock_level_asc' -> { currentStock: 'asc' }, 'created_at_desc' -> { createdAt: 'desc' }, 'category_asc' -> { category: 'asc' }. 'expiry_asc' uses raw SQL joining StockBatch to find nearest expiry.
      - WHERE isActive = true
      - Paginate with skip/take (default limit: 30)
      - Include barcodes, calculate nearest expiry from active batches.
      Return { items, total, page, limit }.

    - `getSummary(clinicId)`: Use raw SQL to get totalItems (count where isActive), lowStockCount (count where currentStock < parLevel AND parLevel IS NOT NULL), expiringCount (count distinct items with batches expiring within configurable lead days AND currentQty > 0), totalValue (SUM of currentStock * sellingPrice).

    - `addBarcode(clinicId, itemId, code, format)`: Create InventoryBarcode. Catch unique constraint violation on [code, clinicId] and throw descriptive error.

    - `removeBarcode(barcodeId, clinicId)`: Delete InventoryBarcode where id and clinicId match.

    - `findByBarcode(clinicId, code)`: Find InventoryBarcode where code and clinicId match, include item with barcodes and active batches.

    - `getBarcodeCatalog(clinicId, updatedSince?: Date)`: Find all InventoryItems with barcodes, optionally filtered by updatedAt > updatedSince. Return lightweight mapping: { items: [{ id, name, category, unit, currentStock, barcodes: [{ code, format }] }] }. Used for offline cache sync (D-19).
