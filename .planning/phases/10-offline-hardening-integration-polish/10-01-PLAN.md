## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Mobile replay payloads → API sync ingress | Untrusted offline operation envelopes cross into trusted replay services |
| Local SQLite working set → mobile UX | Cached clinical and queue data becomes visible on-device during offline use |
| Prisma sync schema → live database | Stale schema would invalidate replay idempotency and conflict persistence assumptions |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-10-02 | Information Disclosure | Local working-set cache | mitigate | Limit local tables to same-day queue/patient/consultation/inventory snapshots per D-15 to D-17 instead of a full clinic mirror |

</threat_model>
