## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Offline scanner/store → replay service | Untrusted local stock operations become server-side stock changes |
| Replay reconciliation → inventory truth | Bad replay handling can corrupt batch/expiry/FIFO state |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-07 | Tampering | Inventory replay payloads | mitigate | Validate inventory replay envelopes and apply idempotent replay receipts before changing stock state |
| T-10-08 | Integrity | FIFO batch reconciliation | mitigate | Re-check live batch/expiry state in `inventoryOfflineReplay.service.ts` before applying queued dispense/return actions |
| T-10-09 | Repudiation | Inventory mismatches | mitigate | Persist operational review tasks through `inventoryConflictReview.service.ts` instead of silently overwriting stock truth |
</threat_model>
