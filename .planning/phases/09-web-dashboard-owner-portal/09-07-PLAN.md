## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-20 | Information Disclosure | Care-dates endpoint | mitigate | Enforce pet scope via AccessScopeService before querying vaccination/deworming/appointment data; return 403-style empty envelope for out-of-scope petIds |
| T-09-21 | Spoofing | Token validation for care-dates | mitigate | Reuse the same magic-link validation middleware from 09-05 routes; no separate auth path |
| T-09-22 | Information Disclosure | Vaccination/deworming data projection | mitigate | Project only vaccineName, drugName, nextDueDate, and status; do not expose clinical notes, dosage, batch numbers, or internal IDs to the owner portal |
</threat_model>
