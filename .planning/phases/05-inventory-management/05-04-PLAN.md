<objective>
Build the mobile inventory list screen, item profile screen, and item creation/edit form. This plan creates the primary inventory browsing experience: the tab landing with summary dashboard, attention alerts, searchable/filterable item list, detailed item profile with batch/history/details tabs, and the item creation form.

Purpose: These screens are the inventory hub that users navigate to for all stock management tasks. The list screen is the entry point from the bottom tab bar. The item profile provides the detailed view with action buttons that launch stock receipt, dispense, and adjustment flows (built in Plan 06).

Output: Three complete screens with all supporting components, hooks, and API integration.
</objective>

    React Query hooks for inventory API calls:
    - `useInventoryItems(clinicId, { search, category, sort, page })`: useQuery fetching GET /api/v1/inventory/items with query params. queryKey: ['inventory', 'items', clinicId, search, category, sort, page].

    - `useInventoryItem(clinicId, itemId)`: useQuery fetching GET /api/v1/inventory/items/:itemId. queryKey: ['inventory', 'item', clinicId, itemId].
    - `useItemMovements(clinicId, itemId, page)`: useQuery fetching GET /api/v1/inventory/items/:itemId/movements. queryKey: ['inventory', 'movements', clinicId, itemId, page].
    - `useCreateItem(clinicId)`: useMutation for POST /api/v1/inventory/items. Invalidates items and summary queries on success.
