<objective>
Create the ServiceCatalog Prisma model and seed it with 20 default veterinary service presets covering ONB-02's "default service catalog presets (consultation, vaccination, surgery, grooming)" requirement. The seed function creates per-clinic copies so each clinic can customize prices independently. This mirrors the drug seed pattern from 04-02 and makes services available from Phase 4 onward so consultations can reference them. Phase 6 builds on this foundation with CRUD endpoints and the ServicePicker UI.

Purpose: ONB-02 requires seed data shipped with the system. Drug database and breed lists are covered elsewhere. This plan delivers the service catalog presets -- the billable service entries that appear in the Phase 6 invoice builder. Creating the model and seed data now (Phase 4) means the ServiceCatalog is available during EMR development and does not block Phase 6.

Output: ServiceCatalog Prisma model with migration, shared TypeScript types and zod schema for billing, 20-entry seed data file with idempotent per-clinic seed function, seed tests, and Prisma seed script integration.
</objective>
