<objective>
Build automated reminders (WHA-01): due-date discovery over Phase 4 tables, idempotent `WhatsAppReminderTask` rows, the bounded escalation state machine, and a Redis-coordinated daily sweep at 08:30 IST.

Purpose: D-01 and D-02 define a two-touch cadence (an advance heads-up and a reminder on the day) which mirrors how a caring front-desk person actually nudges an owner; D-03 and D-04 bound the follow-up so the system never nags indefinitely while still surfacing genuinely stuck cases to a human. The mechanism matters: this project's Redis runs `--maxmemory 128mb --maxmemory-policy allkeys-lru`, so a 12-month delayed job can silently disappear; and `node-cron` fires once per ECS task, so the existing cron precedent would duplicate every send once the service scales past one task. Postgres owns the schedule; BullMQ owns only the daily trigger and second-scale delays.

Output: source repository with latest-record-only queries, task repository and service, the sweep job with scheduler registration, three unit suites and the reminder-idempotency integration suite.
</objective>
