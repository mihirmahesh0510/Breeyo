<objective>
Build the mobile prescription workflow: searchable drug database with client-side caching, medication entry form with formulation selection, species-specific dosage validation with soft warnings, route/frequency/duration selectors, dispensed/prescribed toggle, auto-generated owner-friendly instructions, Repeat Rx from past visits, and prescription list management.

Purpose: Prescriptions are the most data-intensive part of the consultation. The drug search must be instant (client-side), dosage warnings must be visible but non-blocking (soft), and owner-friendly instructions must auto-generate to save the vet time.

Output: Complete prescription workflow from drug search through medication list with dosage safety.
</objective>

  <action>
    **1. Create `useDrugSearch.ts`** (per D-25, Pitfall 5):

    - On app start, fetch full drug list: `useQuery({ queryKey: ['drugs'], queryFn: () => api.get('/api/v1/drugs'), staleTime: Infinity })`. This caches all 300 drugs (~50KB) locally.
    - `searchDrugs(query: string)`: Client-side search using `String.prototype.includes()` on drug.name and drug.genericName (case-insensitive). Return matching DrugEntry[] with formulations. Debounce 300ms.
    - Export hook: `useDrugSearch()` returns `{ drugs, searchDrugs, results, isLoading }`.

    **2. Create `useDosageCalculation.ts`** (per D-26, D-28):

    - `calculateDosageWarning(enteredDoseMg: number, petWeightKg: number, drugId: string, species: string)`:
      Find speciesDosage from cached drug data. If found, use local validation (same logic as DosageService on server). If not found in cache, call API: POST /api/v1/consultations/validate-dosage.
    - `generateOwnerInstructions(prescription: Partial<PrescriptionItem>)`:
      Build string: "[dosage] [route lowercase] [frequency lowercase] for [duration]".
      Examples:
      - "1 tablet (250mg) by mouth twice daily for 7 days"
      - "5ml oral suspension twice daily for 5 days"
      - "1 injection (subcutaneous) once" for single-dose injectables
    - Export hook: `useDosageCalculation(petWeightKg, species)` returns `{ validateDosage, generateInstructions }`.

    **3. Create `DrugSearchModal.tsx`** (per D-25, D-27, UI-SPEC Drug Search Modal States):

    - Full-screen modal on mobile
    - Search input at top: 48px height, auto-focus, placeholder "Search drug name..."
    - Debounced 300ms client-side search
    - Results FlatList: each row 56px, shows:
      - Drug name + generic name: "[Name] ([Generic Name])" in titleMedium
      - Category badge (chip)
      - Below: formulation options as small chips: "Tablet - 250mg", "Suspension - 50mg/ml"
    - States per UI-SPEC:
      - Default: search input focused, empty area
      - Searching: 3 skeleton rows (56px each) during 300ms debounce
      - Results: FlatList of DrugResultRows
      - No Results: "Drug not found. You can enter details manually." + "Manual Entry" button
      - Manual Entry: opens blank MedicationForm with all fields empty
    - Tapping a drug result -> selects drug, transitions to MedicationForm
    - Tapping a specific formulation chip -> pre-selects that formulation in MedicationForm

    **4. Create `MedicationForm.tsx`** (per D-25-D-35, UI-SPEC Prescription Section):

    - Pre-filled from selected drug: drug name, generic name, formulation options
    - Fields:
      - Drug name (read-only if from search, editable if manual)
      - Formulation selection: chip group from drug.formulations
      - Dosage: TextInput with numeric keyboard, placeholder "e.g., 250mg or 5ml"
      - Route: Dropdown from ROUTES_OF_ADMINISTRATION (auto-suggested from formulation: tablet->Oral, injectable->Injectable (IM), drops->Eye Drops). Vet can override
      - Frequency: chip group from MEDICATION_FREQUENCIES + "Custom" option
      - Duration: dropdown from DURATION_OPTIONS. If "Custom" selected, show numeric input for days
      - Dispensed/Prescribed toggle: two-segment control, default "Dispensed" (D-33)
      - Clinical notes: optional TextInput
    - DosageWarning component shown below dosage field when out of range
    - OwnerInstructionsPreview shown at bottom: auto-generated owner-friendly text (D-35)
    - "Add" button (or "Save" if editing) at bottom, primary filled
    - "Cancel" text button

    **5. Create `MedicationCard.tsx`** (per D-29, UI-SPEC):

    - Card (72px compact) showing:

      - Dosage + route + frequency + duration in bodyLarge: "250mg Oral Twice daily for 7 days"

      - Owner-friendly preview in caption
