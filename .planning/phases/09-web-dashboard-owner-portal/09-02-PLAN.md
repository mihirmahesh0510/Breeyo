<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Authenticated browser session → web-dashboard APIs | Untrusted browser requests attempt to read or mutate clinic web-access policy and cockpit data |
| Cockpit payload → browser shell/navigation | Incorrect policy mapping can leak hidden modules or risky actions into the UI |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-04 | Elevation of Privilege | Access-policy service | mitigate | Derive browser module visibility from server-side `ClinicBrowserAccessPolicy` and ignore client-supplied role/module claims |
| T-09-05 | Information Disclosure | Cockpit aggregation | mitigate | Omit unauthorized module panels entirely from cockpit payloads and sidebar navigation instead of shipping placeholder metadata |
| T-09-06 | Repudiation | High-risk browser actions | mitigate | Require `HighRiskConfirmDialog` plus actor/timestamp data from API payloads for access changes, refunds, voids, and sensitive stock edits |
</threat_model>
