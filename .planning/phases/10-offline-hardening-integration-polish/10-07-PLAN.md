<interfaces>
Performance targets from PLT-07 and ROADMAP Phase 10 success criteria #4:

- Mobile app cold start: less than 3 seconds on mid-range Android (Galaxy A14 / Redmi Note 12 class device, Android 12-13, 4GB RAM)
- API p95 response time: less than 500ms across all major endpoint groups (auth, queue, EMR, inventory, billing, sync)
- Queue real-time update latency: less than 2 seconds from server-side queue state change to client-side render on a connected device

Measurement methodology:
- Cold start: Time from activity launch (or `adb shell am start`) to first meaningful paint (queue screen rendered). Maestro `assertVisible` timestamp delta or `adb` logcat `Displayed` time.
- API p95: Vitest bench mode or a lightweight load script using `autocannon` / raw `fetch` loops. Measure over 100+ requests per endpoint group, compute p95 from sorted response times.
- Queue real-time update: Socket.IO round-trip from server emit of a queue status change to the client receiving and rendering the update. Measured via timestamp instrumentation in the Socket.IO event flow.

Real hardware per D-31: Emulator-only measurements are insufficient. The human checkpoint requires real mid-range Android device confirmation.
</interfaces>
