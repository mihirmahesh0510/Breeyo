<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| mobile client → authenticated API | The client can only ever request; all gating is server-side |
| socket connection → cache invalidation | Server events drive client refetches |
| staff note input → outbound message | Staff free text becomes part of the record |
| local optimistic cache → displayed truth | An optimistic row must not outlive a server rejection |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-14-01 | Elevation of Privilege | client-side warnings treated as the security gate | mitigate | All enforcement is server-side: the STOP gate (403 OWNER_OPTED_OUT), SEND_WHATSAPP permission and MANAGE_CLINIC_SETTINGS all live in the API. The sheet's disable-on-opted-out is a usability affordance layered on top, and the consent warning deliberately does not disable Send (D-13) |
| T-07-14-02 | Spoofing | socket connection accepted without authentication | mitigate | `io(API_URL, { auth: { token: accessToken } })` reuses the existing JWT handshake that already scopes clients into `clinic:{clinicId}`; the hook is disabled without a token |
| T-07-14-03 | Repudiation | an optimistic Queued bubble persisting after the server rejected the send | mitigate | `onError` rolls back to the snapshot and `onSettled` invalidates from the server after 300ms, so the server row is always the final truth |
| T-07-14-04 | Tampering | staff editing the template body to send arbitrary text to an owner | mitigate | The sheet exposes only an additive staff note capped at 500 characters; the body is rendered server-side from the frozen registry and there is no body input. Acceptance criteria greps for zero body-editing identifiers |
| T-07-14-05 | Information Disclosure | owner mobile numbers or message bodies logged from the client | mitigate | No console logging of thread, message or owner payloads is added; errors surface through mapped UI copy, not raw payload dumps |
| T-07-14-06 | Denial of Service | unbounded thread pagination or a runaway socket reconnect loop | mitigate | The server caps page size at 50; the socket hook reuses the queue hook's bounded reconnection settings (reconnectionDelay 1000, reconnectionDelayMax 10000) |
| T-07-14-07 | Elevation of Privilege | a non-Admin appearing to change simulator settings | mitigate | `useUpdateSimulatorConfig` surfaces the server's 403 as an Admin-only message; the client never assumes success |
| T-07-14-SC | Tampering | npm/pip/cargo installs | mitigate | No packages installed; the mobile dependency set was resolved and gated in 07-03 |
</threat_model>
