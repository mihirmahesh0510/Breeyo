    **1. Create `apps/api/src/modules/emr/consultation-lock.service.ts`:**

    Class `ConsultationLockService` with constructor accepting PrismaClient:

    - `acquireLock(consultationId: string, vetId: string, vetName: string): Promise<{ acquired: boolean; lockedBy?: string }>`:
      Check if lock exists for consultationId. If exists and not stale (expiresAt > now()), return { acquired: false, lockedBy: existingLock.vetName }. If exists and stale, delete old lock and create new. If not exists, create lock with expiresAt = now() + 5 minutes. Return { acquired: true }.

    - `heartbeat(consultationId: string, vetId: string): Promise<boolean>`:
      Update lock: set lastHeartbeat = now(), expiresAt = now() + 5 minutes. WHERE consultationId AND vetId match. Return true if updated, false if lock not found or wrong vet.

    - `releaseLock(consultationId: string, vetId: string): Promise<void>`:
      Delete lock WHERE consultationId AND vetId match. No-op if not found.

    - `isLocked(consultationId: string): Promise<{ locked: boolean; vetName?: string; stale?: boolean }>`:
      Find lock. If exists and expiresAt > now(): { locked: true, vetName }. If exists and stale: { locked: true, vetName, stale: true }. If not exists: { locked: false }.

    Lock TTL: 5 minutes (300000ms). Heartbeat interval: 60 seconds (client-side).

Otherwise, calculate dosePerKg = enteredDoseMg / petWeightKg and compare against min/maxDoseMgPerKg. Return DosageWarning with message like "Recommended: X-Y mg/kg (A-Bmg for Wkg)" or null if within range.

    - `generateOwnerInstructions(prescription: PrescriptionItem): string`:

    - `createConsultation(clinicId, petId, vetId, queueEntryId, visitType)`: Creates Consultation record with status='draft'. Returns Consultation.

    - `findActiveConsultation(clinicId, petId)`: Finds Consultation where petId matches AND status='draft'. Returns Consultation or null. Used for D-06 check.

      1. Update Consultation with all draft data fields, set status='finalized', finalizedAt=now(), durationMinutes
      2. Upsert Vitals from draftData.vitals
      3. Delete all existing Prescriptions for this consultation, bulk create from draftData.prescriptions
      4. Set followUpDate/Reason if provided
      5. Delete ConsultationDraft record (no longer needed)

    - `updatePetWeight(petId, weightKg)`: Update Pet.weight field (D-14 auto-update).

    - `updateQueueEntryStatus(queueEntryId, status: 'DONE', completedAt: Date)`: Update QueueEntry status to DONE with completedAt timestamp.

    - `getConsultation(consultationId, clinicId)`: Find Consultation with include { vitals, prescriptions, attachments }. WHERE clinicId matches.

    - `getHistory(clinicId, petId, limit: number)`: Find all Consultations where petId matches, status='finalized', ordered by startedAt desc, take limit. Select summary fields (id, visitType, status, startedAt, finalizedAt, durationMinutes, assessment, vetId). Include prescriptions count and attachments count.

    - `addAddendum(consultationId, addendum: AddendumEntry)`: Read current addenda array, append new entry, update Consultation.addenda field.

    - `savePrescriptions(consultationId, items: PrescriptionItem[])`: Delete existing + bulk create. Each item gets sequential sortOrder.

    **4. Create `apps/api/src/modules/emr/emr.service.ts`:**

    Class `EmrService` with constructor accepting EmrRepository, ConsultationLockService, DosageService:

    - `createConsultation(clinicId, petId, vetId, input: CreateConsultationInput)`:
      1. Validate with createConsultationSchema.parse(input)
      2. Check for active consultation: repository.findActiveConsultation(clinicId, petId). If exists, throw conflict error with lock info (D-06)
      3. Create consultation: repository.createConsultation(...)
      4. Acquire lock: lockService.acquireLock(consultation.id, vetId, vetName)
      5. Return consultation

    - `saveDraft(consultationId, clinicId, vetId, data: SaveDraftInput)`:
      1. Validate sections present with saveDraftSchema
      2. Verify lock is held by this vet
      3. Save to draft table: repository.saveDraft(consultationId, clinicId, data)

    - `finalize(consultationId, clinicId, vetId, input?: FinalizeInput)`:
      1. Load draft from repository
      2. Calculate durationMinutes = Math.round((now - consultation.startedAt) / 60000)
      3. In repository transaction:
         - Finalize consultation with all draft data
         - If vitals.weightKg exists, update pet weight (D-14)
         - If queueEntryId exists, update queue entry status to DONE (D-04)
      4. Release lock: lockService.releaseLock(consultationId, vetId)
      5. Return finalized consultation

    - `addAddendum(consultationId, clinicId, vetId, vetName, text)`:
      1. Validate with addendumSchema
      2. Verify consultation is finalized (not draft)
      3. Create AddendumEntry: { id: cuid(), text, addedBy: vetId, addedByName: vetName, addedAt: new Date() }
      4. repository.addAddendum(consultationId, entry)
