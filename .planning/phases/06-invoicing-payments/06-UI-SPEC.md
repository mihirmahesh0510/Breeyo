# Phase 6 -- UI Design Contract

> Visual and interaction contract for Invoicing and Payments. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> This phase ties together consultation services (Phase 4) and dispensed inventory (Phase 5) into a billing workflow. All tokens, base components, and interaction patterns from 02-UI-SPEC.md are inherited and NOT re-declared here. Phase 3 patterns (pet profile tabs, live search), Phase 4 patterns (PDF generation, floating bar), and Phase 5 patterns (barcode scanner, FIFO dispense, counter sale badge) are consumed where applicable. This document specifies what Phase 6 adds or refines for the invoice builder, payment integration, Quick Sale, credit notes, refunds, and billing dashboard.

## Spacing Scale

Inherited from Phase 2 UI-SPEC (8px base unit). No modifications.

| Token | Value | Phase 6 Usage |
|-------|-------|---------------|
| `spacing.xs` | 4px | Icon-to-label gap in invoice line items, status badge internal padding, payment method icon gap |
| `spacing.sm` | 8px | Line item row internal spacing, filter chip spacing, payment split row gaps, credit note item spacing |
| `spacing.md` | 16px | Invoice card internal padding, form field gaps, bottom sheet content padding, QR code container padding, billing settings form gaps |
| `spacing.lg` | 24px | Section gaps within invoice detail (line items vs totals vs payment), gap between summary cards and invoice list, Quick Sale cart padding |
| `spacing.xl` | 32px | Screen-level horizontal margins, gap between billing dashboard sections |
| `spacing.2xl` | 40px | Vertical gap above floating action area on invoice builder |
| `spacing.3xl` | 48px | Bottom padding above tab bar safe zone |

Exceptions:
- **Touch targets**: 44x44pt minimum enforced on all invoice cards, service catalog items, payment method selectors, line item remove buttons, QR code tap-to-enlarge area (Phase 2 standard).
- **Summary cards height**: 64px per summary card (Today's Revenue, Unpaid Total, Overdue Count, Recent Payments). Same pattern as Phase 5 SummaryHeader.
- **Invoice list card height**: 80px per card (invoice number + date + pet name + amount + status badge -- spacious for glanceability during busy billing hours).
- **Invoice line item row height**: 48px per line item (compact density for tabular financial data per Phase 2 D-32).
- **Quick Sale cart item height**: 56px per cart item (name + qty stepper + price -- balanced density for counter interactions).
- **QR code display**: 200px x 200px centered within a 248px x 248px container (24px padding). Positioned centrally in the payment bottom sheet.
- **Payment method selector height**: 56px per payment method option (Cash, UPI, Card -- generous tap targets for quick selection).
