<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| server data → rendered message body | Owner-authored and template-rendered text is displayed to staff |
| owner phone number → on-screen display and logs | Personal data under India's DPDP Act |
| component props → action handlers | A component must not be able to invent a privileged action |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-06-01 | Elevation of Privilege | a presentational component constructing a booking cancel/move payload | mitigate | Components accept `onPress` handlers only; `ConversationActionCard` never builds a payload id, and 07-02's inbound payload grammar excludes cancel/move entirely (D-09). Acceptance criteria asserts no `apiClient`/`useMutation` in these files |
| T-07-06-02 | Information Disclosure | full owner phone numbers written to console/Sentry from the mobile client | mitigate | The formatting module has no logging; components render the number but never log it. No `console.log` of thread or message data is introduced |
| T-07-06-03 | Tampering | message body rendered as markup, letting owner text alter the UI | accept | React Native `Text` does not interpret HTML or markup, so owner-authored strings render as literal text. No `dangerouslySetInnerHTML` equivalent exists in RN. Length caps from 07-02 bound the content |
| T-07-06-04 | Repudiation | a failed message rendered as if it had succeeded | mitigate | `MessageStatusBadge` always renders the text label alongside color and icon; `failureCopy` has a total fallback so an unmapped code still renders a failure message rather than `undefined` |
| T-07-06-05 | Denial of Service | an unbounded preview string breaking the inbox layout | mitigate | `truncatePreview` caps previews at 80 characters and returns the UI-SPEC empty-state string for blank input |
| T-07-06-SC | Tampering | npm/pip/cargo installs | mitigate | No packages installed in this plan; the dependency set was resolved and gated in 07-03 |
</threat_model>
